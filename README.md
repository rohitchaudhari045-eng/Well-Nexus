# WellNexus

## AI-Powered Nearby Wells Intelligence System (NWIS)

Developed for Oil India Limited under Smart India Hackathon (SIH).

### Problem Statement

Drilling engineers often spend significant time searching historical drilling reports, offset well data, and operational records before making critical decisions.

WellNexus provides a centralized AI-powered platform that helps engineers access nearby well intelligence, historical incidents, risk predictions, and drilling knowledge in real time.

---

## Key Features

- Nearby Wells Mapping
- Active Well Monitoring
- AI Search Assistant
- OCR Document Intelligence
- Historical Knowledge Repository
- Formation Correlation
- Risk Prediction Engine
- Real-Time Alerts
- Analytics Dashboard
- Admin & Data Quality Console
